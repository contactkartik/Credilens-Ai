# CrediLens AI

Information Credibility Detection Using NLP, Multimodal Analysis and Explainable AI

## Project Overview

CrediLens AI is an M.Tech project that aims to detect the credibility of information using advanced Natural Language Processing (NLP), multimodal analysis techniques, and Explainable AI principles.

## Project Structure

```
CrediLens-AI/
├── backend/          # FastAPI backend application
├── frontend/         # React frontend application
├── ml/              # Machine learning pipeline components
├── data/            # Dataset storage
├── models/          # Trained model artifacts
├── notebooks/       # Jupyter notebooks for experiments
├── docs/            # Project documentation
├── scripts/         # Utility scripts
└── tests/           # Integration tests
```

## Key Features

- **NLP Analysis**: Text-based credibility assessment
- **Multimodal Analysis**: Combining text, image, and metadata features
- **Explainable AI**: Transparent decision-making process
- **Real-time Inference**: Fast credibility scoring

## Setup Instructions

1. Clone the repository
2. Copy `.env.example` to `.env` and configure variables
3. Install backend dependencies
4. Install frontend dependencies
5. Train ML models (see documentation)
6. Run backend and frontend servers
